## Дані та предметна постановка

Quinlan, R. (1993). Auto MPG, UCI. DOI https://doi.org/10.24432/C5859H. Ліцензія **CC BY 4.0**; при поширенні зберігайте атрибуцію. Файл отримано для ЛР №2 17.11.2026 й скопійовано без змін. Оригінальний URL архіву: https://archive.ics.uci.edu/static/public/9/auto%2Bmpg.zip; використано `auto-mpg.data`. SHA-256 та походження — `outputs/metadata/source.json`.

Прогнозуємо mpg для ще не представлених назв автомобілів того самого періоду 1970–1982. Немає твердження про якість на сучасних авто. У звіті зіставлено предметні джерела DOE та EPA, пояснено дві гіпотези з EDA, подано їхню розвідувальну інтерпретацію.

## Протокол

Seed 312024, поділ за точною нормалізованою назвою авто: 316 train (244 назви), 82 test (61 назва), без перетину назв. Усередині train — 5-fold групова CV × 3 повтори. Медіана horsepower оцінюється тільки в analysis-частині кожного fold. Кандидати: середнє train, M1 (маса, потужність, рік, походження), M2 (M1 + квадрат маси). Основна метрика — RMSE, додаткова MAE, у mpg.

Вибір M2 за CV записано в `selection.json` до оцінювання test. На test оцінено лише обрану M2 й константу. RMSE M2 = 2,776 mpg, MAE = 1,947 mpg, RMSE константи = 8,293 mpg. Навчальна CV: RMSE M1 = 3,384, M2 = 3,077 mpg. Висновки не є причинними; весь набір уже переглядався в попередньому EDA, тому test не названо незалежним зовнішнім підтвердженням.

`data/processed/prepared_data.csv` містить передобробку з медіаною всього train для повторного використання фінальної моделі. **Не використовуйте цей CSV для підбору CV:** звіт завжди читає raw й повторно оцінює медіани всередині folds. Належність рядків визначено в `outputs/tables/split.csv`.

## Відтворення з чистої копії

Використано **R 4.6.1**, **Quarto 1.11.9**, renv 1.3.1 для збереження версій. Точні версії 39 пакетів і їхні джерела зафіксовані в `renv.lock`. Системний Quarto встановлюється окремо з https://quarto.org/docs/get-started/. На Windows потрібен доступний R; якщо Quarto не знаходить його, задайте `QUARTO_R` як шлях до каталогу R `bin`.

З кореня репозиторію виконайте:

```sh
Rscript restore.R
quarto render
```

`restore.R` встановлює пакети за lockfile до `renv/library`. `.Rprofile` підключає цю бібліотеку першою. Для свіжого середовища потрібен інтернет до CRAN/архівів пакетів; для перегляду зібраних HTML R не потрібен. Для відтворення не використовуйте `Rscript --vanilla`: цей параметр вимикає `.Rprofile` з локальною бібліотекою. Метадані R-сеансу — `outputs/metadata/session_info.txt`.

Якщо відповідна версія вже встановлена, `restore.R` повторно використовує її після перевірки номера версії. Інакше renv завантажує її. Для архівних версій без Windows-бінарників потрібен сумісний із вашою R набір [Rtools](https://cran.r-project.org/bin/windows/Rtools/); на Linux — компілятор і системні залежності пакетів. Перевірка в цій роботі використовує нову папку проєкту та нову локальну бібліотеку, заповнену встановленими пакетами точних версій і кешем renv. Повне встановлення з джерельних архівів на іншій ОС не перевірялося.

Спочатку виконується `reports/Regression.qmd`, потім `reports/Presentation.qmd`: слайди читають уже збережені результати, а не навчають моделі заново. Результати — `reports/Regression.html` та `reports/Presentation.html`. Повторний запуск відтворює той самий зафіксований протокол, а не виконує новий пошук за test. Код моделей міститься безпосередньо в `.qmd`; службових генераторів notebook немає.

Основні залежності: data.table 1.18.6.1, ggplot2 4.0.3, jsonlite 2.0.0, knitr 1.52, rmarkdown 2.32. Для максимально близького відтворення використайте зазначену версію R й Quarto. Можливі незначні відмінності рендерингу шрифтів між ОС.
